# 战斗伤害计算系统重构规范

## 1. 变更概述

### 1.1 背景
当前战斗伤害计算使用三维属性（武力、智力、统帅）取最大差值作为攻防基础，与用户要求的"攻击力=武力、防御力=统帅"不一致，且伤害区间不够合理。

### 1.2 核心改动
- **攻击力**：`武力(Str)` + 兵力加成
- **防御力**：`统帅(LeadShip)`
- **伤害公式**：基于攻击和防御的差值计算，伤害区间调整为 **10-60**
- **兵力影响**：每50个兵力增加1点攻击力

## 2. 详细改动

### 2.1 文件：Chess.cs

#### 2.1.1 属性变更

**Init方法** (约line 151)：
- 当前：`attackDamage = leadShip / 3`
- 修改为：`attackDamage = str / 3`

#### 2.1.2 伤害计算方法重写

**CalculateDamage方法** (约line 645-677)：

```csharp
private static int CalculateDamage(Chess attacker, Chess defender, out string type)
{
    if (!attacker.isHero || !defender.isHero)
    {
        type = "leadShip";
        return attacker.attackDamage;
    }

    int attackPower = attacker.str + attacker.hp / 50;  // 武力 + 兵力/50
    int defensePower = defender.leadShip;                  // 统帅作为防御力

    int powerDiff = attackPower - defensePower;

    // 伤害 = 30 + (攻击防御差) / 2
    // 当攻击=防御时，伤害为30
    int damage = 30 + powerDiff / 2;

    // 记录攻击类型
    type = "str";

    return damage;
}
```

#### 2.1.3 伤害clamp范围调整

**Attack方法** (约line 564-588)：

- 当前最小伤害：`10 + level / 2`
- 当前最大伤害：`50 + level`

修改为：
```csharp
int minDamage = 10;
int maxDamage = 60;
```

保持等级压制的百分比调整逻辑不变。

## 3. 伤害公式设计

### 3.1 基础公式
```
攻击力 = 武力(Str) + 兵力 / 50
防御力 = 统帅(LeadShip)
伤害 = 30 + (攻击力 - 防御力) / 2
```
**注**：武力+兵力/50与统帅的差值除以2后加30，保证在攻防差为0时基础伤害为30

### 3.2 伤害区间控制
- **最小伤害**：10点（保证最低输出）
- **最大伤害**：60点（保证平衡）

### 3.3 公式特性
| 攻击方 | 防守方 | 攻防差 | (差/2)+30 | 最终伤害(CLAMP) |
|--------|--------|--------|----------|----------------|
| 40武力, 500兵 | 40统帅 | 10 | 30+5=35 | 35 |
| 100武力, 500兵 | 100统帅 | 10 | 30+5=35 | 35 |
| 100武力, 500兵 | 40统帅 | 60 | 30+30=60 | 60 |
| 100武力, 1000兵 | 100统帅 | 20 | 30+10=40 | 40 |
| 80武力, 500兵 | 100统帅 | -10 | 30-5=25 | 25 |
| 60武力, 500兵 | 100统帅 | -40 | 30-20=10 | 10 |
| 40武力, 2000兵 | 100统帅 | -20 | 30-10=20 | 20 |
| 100武力, 2000兵 | 40统帅 | 100 | 30+50=80→60 | 60 |

### 3.4 兵力影响示例
- 500兵力 = +10攻击力
- 1000兵力 = +20攻击力
- 2000兵力 = +40攻击力

## 4. 改动影响分析

### 4.1 平衡性影响
1. **高武力英雄**：伤害输出显著提升（如吕布、关羽等）
2. **高统帅英雄**：防御能力更强，更能抗伤害
3. **兵力规模**：大兵力部队在攻击力上有明显优势
4. **智力属性**：不再直接影响战斗伤害，智将定位更偏向辅助

### 4.2 需要关注的英雄
- **吕布**：武力100，150武力+500兵=60攻击力（接近上限）
- **诸葛亮**：智力100但武力45，输出较低但依然是强辅助
- **曹操**：武力81，统帅98，属于攻守兼备型
